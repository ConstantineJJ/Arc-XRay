# Как пользоваться Arc-XRay

## Установка и первый запуск

Нужны Python 3.10+ с командой `python3`, Git и актуальный Codex CLI. В Windows
команды Bash можно выполнять через Git Bash. Python должен быть доступен и
самому desktop-приложению, а не только одному терминалу.

```bash
codex plugin marketplace add ConstantineJJ/Arc-XRay && codex plugin add arc-xray@arc-xray
```

Откройте новый локальный чат и выберите Arc-XRay. Если инструменты не появились,
перезапустите приложение и повторите проверку. Укажите папку проекта или текущий
workspace. Не нужны API key, pip/npm и обязательный облачный сервис.

Пример запроса:

> Исследуй этот проект без изменения исходников. Покажи точки входа, модули,
> зависимости и хранение данных. Проследи успешный запрос, ошибку и повтор или
> отмену операции. Проверь противоречия, избыточность, связанность и возможные
> проблемы эффективности. Дай доказательства и ограничения, index.html и просмотр
> внутри приложения.

Сначала агент получает автоматическую карту, затем читает важные исходники и
дополняет её смысловыми описаниями, связями и выводами. Надпись о том, что смысловое
ревью ещё не добавлено, означает именно автоматическую начальную карту.

## Встроенный просмотр

Локальный сервер предоставляет MCP App. Инструменты `arc_xray_audit`,
`arc_xray_enrich` и `arc_xray_open` могут открыть интерактивную карту в совместимом
клиенте. Данные для просмотра и `index.html` строятся из одной модели.

Обычный веб- и мобильный ChatGPT не запускает локальный stdio-процесс и не читает
диск компьютера. Там нужны доступные исходники и отдельный доступный runtime или
окружение приложения с Python и HTML preview. Этот репозиторий не разворачивает
публичный сервер. Установка через GitHub также не равна одобрению общего каталога.

Для другого MCP-клиента настройте `python3 -B /путь/Arc-XRay/arc-xray.py mcp
--data-dir /путь/к/атласам --allow-root /путь/к/проектам`. Аргумент `--allow-root`
необязательный и повторяемый; с ним сервер отклоняет проекты вне заданных корней.
Без него граница чтения — явно переданная папка конкретного аудита. Корень диска
и домашняя папка целиком отклоняются. Соответствие исходных папок хранится в
локальном sessions.json внутри данных плагина; экспорт атласа содержит относительные пути.

## Карта, дерево и управление

- Слева выбираются разделы. Клик по компоненту или стрелке открывает описание,
  входы/выходы, связи и раскрываемые фрагменты исходников справа.
- Поиск охватывает весь атлас, в том числе шаги выполнения. Выбор результата
  открывает подходящий раздел и раскрывает нужную группу.
- Перетаскивайте пустой канвас для перемещения; колесо и +/− меняют масштаб.
  «Вписать» возвращает весь видимый граф. Полные подписи доступны при наведении.
- «Карта» группирует компоненты. Заголовки групп сворачивают и раскрывают их.
  «Дерево» выделяет основные направленные ветви; повторные и циклические связи
  сохраняются. В меню «Вид» можно выбрать корень и скрыть поперечные связи.
- Сплошная стрелка — данные, длинный пунктир — управление, точечный — зависимость.
  Цвет выбирается по отдельной связи, исходному компоненту или типу.
- В меню «Вид» находятся фильтр подтверждения, размер текста, сворачивание и сброс.
  Первоначально рисуются 120 подходящих компонентов; кнопка «Показать больше»
  расширяет выборку. Счётчик показывает число отображённых компонентов, а экспорты
  сохраняют полный граф.
- «Только канвас» или **F** скрывает панели. **Esc** или кнопка выхода возвращает их.
  В MCP App это внутренний режим фокуса; внешний Full screen управляется самим
  приложением. На узком экране панели располагаются друг под другом.

## Риски, несоответствия и логи

Откройте «Риски и несоответствия». В каждом наблюдении есть отдельно установленное
по исходникам свойство, возможное последствие и предлагаемая проверка. Высокий
приоритет не означает доказанную уязвимость или подтверждённую поломку.

Кнопка ↓ в строке или «Создать лог» сохраняет одно наблюдение. «Все наблюдения в
лог» выбирает пачку. Можно изменить состав, имя файла, Markdown/JSON и комментарий,
затем посмотреть содержимое до сохранения.

Если браузер предоставляет Save As, появится диалог выбора папки и имени. Иначе
место определяют настройки загрузок браузера: включите запрос места для каждого
файла. Приложение может ограничивать скачивание в своей панели. Отмена выбора не
теряет лог; при ошибке доступны повтор и явное скачивание. Запись лога не меняет
статус риска на «исправлен» и не правит исходники.

## Результат и проверка

Открывайте созданный **index.html** — это автономный файл с интерактивной картой.
Сервер и соседние файлы для его работы не нужны. `viewer/index.html` в исходном
репозитории — шаблон сборки, а не готовый атлас.

Остальные файлы: `atlas.json` — модель и доказательства, `REPORT.md` — отчёт,
`COMPONENTS.md` — компоненты, `architecture.drawio` — редактируемые страницы
diagrams.net, `flows.md` — Mermaid. В Mermaid каждый раздел ограничен 80 узлами с
уведомлением о пропуске; JSON и draw.io содержат полные разделы.

```bash
python3 -B arc-xray.py validate /путь/к/атласу/atlas.json --project /путь/к/проекту
```

Проверяются ссылки графа и SHA-256 исходников. Это не доказывает правильность
смысловых выводов агента: важные связи надо сверить с кодом. Перед передачей атласа
другим людям просмотрите фрагменты исходников: исключение секретных имён файлов и
маскирование известных шаблонов не гарантируют отсутствия чувствительных данных.

## Ограничения и сохранность

CLI принимает новую/пустую папку либо свой результат с `.arc-xray-output`.
Чужой отчёт не перезаписывается. При пересборке заменяются только известные файлы
атласа; другие файлы сохраняются. Новые копии с номерами и backups не создаются.

Лимиты CLI: 2 000 файлов, 256 KB на файл, 24 MB суммарно. MCP по умолчанию берёт
500 файлов, максимум 2 000. Перебор каталогов ограничен 30 000 записями. Для MCP
App данные свыше 8 MB открываются через offline-файл; для панели сузьте область.
Пропуски, неизвестное и неразрешённые импорты отражаются в покрытии. Зависимости,
build/VCS-каталоги, symlinks/junctions и обычные файлы с секретами пропускаются.
`.gitignore` не интерпретируется; CLI принимает повторяемый `--exclude` с glob
относительно корня проекта.

Python-импорты извлекаются через AST. Для JS/TS, GDScript, Go, Rust и C# используются
ограниченные lexical adapters. Другие типы получают только учёт файлов. Схемы
выполнения Python не моделируют полностью runtime dispatch, finally, async и
динамический код. Нет автоматических fixes, запуска проекта или выдуманных замеров.

Технические контракты: [методика](../skills/arc-xray/references/audit-methodology.md),
[дополнение карты агентом](../skills/arc-xray/references/enrichment.md).
