# Руководство Arc-XRay 0.2

Установите ZIP через Plugins либо используйте команды для своей оболочки из README.
MCP не нужен. Код, шаблон и значок находятся внутри skills/arc-xray/.
Чтение исходников и Python обеспечивает окружение приложения; установка плагина
не добавляет их автоматически. Если Chat не видит локальный проект, предоставьте
исходники доступным в нём способом.

Если приглашение терминала начинается с `PS`, используйте одну PowerShell-строку
из README. Bash-команды в такой терминал вставлять нельзя. Установщик сам находит
Codex; вводить переменные с путями или менять PATH не требуется.

Перед началом агент должен выполнить [проверку окружения](../skills/arc-xray/references/host-environments.md).
В обычном Chat Python и локальные файлы могут находиться в разных средах. Тогда
нужен перенос реального снимка исходников и ресурсов Skill. Если выполнить
канонический генератор нельзя, агент сообщает об ограничении и не создаёт
заменяющий HTML или CMD-запускатель. Плагин не добавляет прав на запуск программ.

## Порядок работы

1. Агент читает полный Skill, находит scripts/arc-xray.py и реальные пути проекта
   и результата. Исходники остаются без изменений и не запускаются.
2. Команда audit создаёт первичное исследование в стандартном синем интерфейсе.
3. Агент читает модули, прослеживает связи и сценарии, описывает входы/выходы,
   записывает ревью и статусы пяти областей. Разбираются успех, ошибка и повтор
   или отмена; отсутствие механизма объясняется, а не выдумывается.
4. review с --finalize собирает тот же атлас и проверяет полноту.
5. validate с --project и --require-complete сверяет ссылки, хеши и записанную
   полноту. Сам смысл выводов всё равно надо проверять по исходникам.
6. В HTML preview открывается тот же index.html, который выдаётся для скачивания.
   Отдельный упрощённый HTML для обычного Chat не создаётся.

Готовые команды без обозначений в угловых скобках — в README. Формат дополнения:
[контракт](../skills/arc-xray/references/enrichment.md). При прерывании работы
сохранённый review.json позволяет продолжить исследование.

## Управление

Слева — разделы и поиск по всему графу. Клик по блоку или стрелке открывает назначение,
входы/выходы, связи и раскрываемые доказательства с SHA-256. Перемещение — за пустой
канвас; масштаб — колесо или +/−; «Вписать» возвращает весь видимый граф.

«Карта» группирует компоненты. «Дерево» строит направленные ветви и сохраняет циклы
и поперечные связи. Большой граф сначала свёрнут по группам, но все компоненты
остаются в модели и раскрываются. Выборки «только первые 120» больше нет.

В меню «Вид» — размер текста, подтверждение, цвет стрелок, корень дерева,
поперечные связи, сворачивание и сброс. Сплошная линия — данные, длинный пунктир —
управление, точечный — зависимость. «Только канвас»/F скрывает панели, Esc возвращает.
Внешним Full screen и доступностью HTML preview управляет приложение.

## Риски и сохранение

Наблюдение, возможное последствие и предлагаемая проверка разделены. Приоритет
не доказывает поломку или уязвимость. Кнопка ↓ сохраняет одно наблюдение, общая
кнопка — пачку. Можно выбрать состав, Markdown/JSON, имя и комментарий, просмотреть
лог. Save As выбирает место при поддержке браузером; иначе действуют настройки
загрузок. Логирование не меняет риск на «исправлен» и не правит исходники.

## Полнота и ограничения

Статусы: первичное исследование, незавершённое ревью, завершённое ревью в заявленной
области. Финальная проверка требует пяти исследованных областей, описаний модулей
и сценариев. Она проверяет записанное покрытие и доказательства, а не гарантирует
верность суждений агента. Нельзя незаметно исключать файлы ради прохождения проверки.

Пределы: 2 000 файлов, 256 KB на файл, 24 MB суммарно, 30 000 записей каталогов.
Для Python есть AST, для других поддерживаемых языков — ограниченные lexical
adapters. Runtime, динамический и generated code полностью не восстанавливаются.
Пропуски и неизвестное должны быть отражены. .gitignore не интерпретируется;
нужные исключения задаются явно через --exclude.

Результат сохраняется только в новую/пустую или свою папку с .arc-xray-output.
При пересборке чужие файлы не удаляются. Перед передачей другим людям проверьте
фрагменты исходников: маскирование секретов не гарантирует конфиденциальность.
JSON/draw.io содержат полный граф; Mermaid ограничивает раздел 80 узлами с явным
уведомлением. Проверки файлов не заменяют фактическую проверку вызова в Chat.
