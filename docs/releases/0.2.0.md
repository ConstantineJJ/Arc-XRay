Arc-XRay 0.2.0 is an independent skill plugin. No MCP server, connector or API key is required.

- The analyzer, canonical blue viewer, localization and icon are self-contained inside the skill.
- Chat/Work downloads and HTML previews use the same index.html and architecture model.
- Finalization checks all five review areas, implementation modules and success/error/retry-or-cancellation paths.
- Large graphs preserve all components using expandable groups.
- Windows PowerShell 5.1 and Git Bash installation are documented separately. Git Bash selects codex.exe on Windows.
- Includes English/Russian guides, source evidence, reports, finding logs, draw.io and Mermaid.

Install the attached ZIP through Plugins → Add → Upload plugin archive, or use the repository marketplace commands in README.
Analysis needs accessible source files and Python 3.10+ in the host environment. The completion gate checks recorded coverage, not runtime correctness.
Native Chat model invocation is a separate acceptance item; no replacement simplified UI should be generated when a host capability is missing.
