Arc-XRay 0.2.1 improves installation and host capability checks.

- One-line PowerShell and Bash installers; automatic detection of the Windows Codex desktop CLI outside PATH.
- Clear missing-CLI and unsupported-command errors; check-only mode makes no installation changes.
- Required execution preflight and source-snapshot transfer guidance for Chat Python environments.
- No substitute hand-written HTML or unsolicited CMD launcher when execution is unavailable.

The analyzer remains independent of MCP and uses the same canonical blue viewer.
Install the ZIP through Plugins > Add > Upload plugin archive, or use the README
command for your shell. Open a new chat after updating.

The plugin cannot add code-execution or local-file capabilities to a host. Native
Chat model behavior is not proven by automated package and browser checks.
