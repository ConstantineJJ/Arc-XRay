# Changelog

## 0.2.0 — 2026-11-15

- Removed mandatory MCP server and bundled its replacement as a self-contained executable skill.
- Standardized the blue viewer for downloaded HTML and host previews.
- Added evidence-backed completion gates for five areas, implementation modules and execution paths.
- Preserved all nodes in large graphs using expandable grouping.
- Added Windows PowerShell 5.1 installation and real copyable examples.
- Updated Russian/English guides, upgrade instructions and Discord description.

## 0.1.0 — 2026-11-15

- Read-only source survey and agent-guided semantic architecture review.
- Autonomous index.html and standard MCP Apps viewer, with map/tree navigation,
  search, filters, source evidence, comfortable text and canvas focus layout.
- Qualified architectural observations and single/bulk Markdown/JSON finding logs.
- JSON, Markdown, editable draw.io and Mermaid exports with explicit coverage limits.
- English/Russian interface, generated review messages and documentation.
- Portable plugin, Codex compatibility, repository marketplace and Bash installation.
- Python standard-library runtime, offline viewer, supplied artwork and MIT license.

Local MCP Apps require a compatible client and local runtime. This release does
not deploy a cloud endpoint or publish to the universal OpenAI plugin directory.
