<h1 align="center">Arc-XRay</h1>
<p align="center">Архитектура проекта — от общей карты до исходников.</p>

[English](README.md) · [Руководство](docs/USAGE.ru.md) · [Возможности и ограничения](docs/CAPABILITIES.md)

Arc-XRay помогает агенту исследовать исходники и создать интерактивный атлас
архитектуры: компоненты, зависимости, движение данных, пути выполнения и
архитектурные проблемы с доказательствами. Результат — автономный **index.html**
и просмотр той же карты внутри совместимого приложения через **MCP App**.

## Установка плагина командой Bash

Нужны **Python 3.10+ с командой `python3`**, Git и актуальный Codex CLI с командами
`plugin marketplace add` и `plugin add`.

```bash
codex plugin marketplace add ConstantineJJ/Arc-XRay && codex plugin add arc-xray@arc-xray
```

Также можно клонировать репозиторий, просмотреть `install.sh` и выполнить
`bash install.sh`. Он проверяет зависимости и использует те же команды.
`bash install.sh --dry-run` только показывает действия.

Откройте новый локальный чат, выберите **Arc-XRay** и напишите:

> Создай атлас архитектуры этого проекта без изменения исходников. Проследи
> основные сценарии, ошибки и противоречия. Дай index.html и встроенный просмотр.

Установка не открывает доступ к чужим исходникам. Пользователь выбирает проект,
который доступен агенту в его окружении.

## Что получится

- Карта и дерево, масштаб и перемещение, поиск, сворачиваемые группы, фильтры,
  разноцветные стрелки, описания компонентов и привязки к строкам исходников.
- Разделы архитектуры, зависимостей, данных/I/O, выполнения и покрытия.
- Ревью ошибок, противоречий, избыточности, связанности, возможных проблем
  эффективности и других рисков. Наблюдения отделены от возможных последствий.
- Логи наблюдений по одному или пачкой, Markdown/JSON, выбор места сохранения
  при поддержке браузером и обычное скачивание как запасной вариант.
- Крупный текст, компактная панель, режим «Только канвас», русский и английский UI.
- Файлы `index.html`, `atlas.json`, `REPORT.md`, `COMPONENTS.md`,
  редактируемый `architecture.drawio` и `flows.md` с Mermaid.

Исследуемый код не запускается и не исправляется. Обязательного облачного
сервера, подписки и API key нет. Для работы готовой версии не нужны pip и npm;
в просмотрщике нет внешних CDN и сетевых зависимостей.

## Без установки плагина

```bash
git clone https://github.com/ConstantineJJ/Arc-XRay.git
cd Arc-XRay
python3 -B arc-xray.py audit /путь/к/проекту --out /путь/к/новому-атласу --language ru
python3 -B arc-xray.py validate /путь/к/новому-атласу/atlas.json --project /путь/к/проекту
```

Откройте созданный **index.html** в браузере. Он работает напрямую через
`file://`, без сервера и соседних файлов. Файл `viewer/index.html` в репозитории —
шаблон сборки; открывать нужно результат команды.

## Просмотр внутри ChatGPT и ограничения

Локальный плагин содержит stdio MCP server и стандартную панель MCP App.
В поддерживающем её клиенте инструменты `arc_xray_audit`, `arc_xray_enrich` и
`arc_xray_open` показывают интерактивную карту рядом с разговором.

Обычный веб- или мобильный ChatGPT сам не запустит локальный процесс и не получит
доступ к диску. Там нужны доступные исходники и отдельный доступный runtime либо
окружение приложения, которое умеет создавать и показывать HTML. В репозитории
нет развёрнутого облачного MCP endpoint. Распространение через GitHub также не
означает публикацию в общем каталоге OpenAI.

Автоматический анализ — начало исследования. Для Python используются AST-импорты,
для JavaScript/TypeScript, GDScript, Go, Rust и C# — ограниченные lexical adapters.
Другие типы получают учёт файлов. Python-схемы выполнения приблизительны и
ограничены по размеру. Смысловое исследование и дополнение карты выполняет агент.

Наблюдение исходника не доказывает поведение runtime; риск не равен подтверждённой
ошибке, а отсутствие автоматических находок не гарантирует качество архитектуры.
